# PaperWritingAgent

## 项目简介

PaperWritingAgent 是一个计划中的论文写作辅助智能体项目，主要面向科研新手，目标是辅助完成文献检索、论文结构规划、文献综述整理、初稿撰写和引用检查等任务。

本项目目前处于学习和规划阶段，主要参考 Datawhale Hello-Agents 项目进行 Agent 基础学习。

## 项目背景

科研论文写作通常包含多个步骤，例如确定研究主题、检索文献、整理相关工作、规划论文结构、撰写初稿和检查引用等。

对于刚入门的研究生来说，这些步骤比较分散，容易出现文献整理混乱、论文结构不清晰、引用不规范等问题。因此，本项目尝试利用 Agent 的任务规划和工具调用能力，将论文写作流程拆分为多个子任务。

## 初步功能模块

### 1. 文献检索模块

根据研究主题或关键词，检索相关论文，并整理论文标题、作者、年份和链接等信息。

### 2. 论文规划模块

根据研究主题和已有文献，生成论文题目建议、章节结构和每一部分的写作目标。

### 3. 文献综述模块

根据已有论文笔记，辅助整理相关工作部分。

### 4. 初稿撰写模块

根据论文大纲和写作素材，生成论文各章节的初步草稿。

### 5. 引用检查模块

检查正文引用和参考文献之间是否存在缺失、不对应或格式不规范的问题。

## 使用方法

当前项目提供了一个最小 Python 原型：

- 文件路径：src/outline_generator.py
- 功能：输入研究主题，识别研究方向，生成论文大纲，并保存为 Markdown 文件

### 运行方式一：交互式输入

python src/outline_generator.py

运行后，根据提示输入研究主题，例如：

LLM 辅助 CAD 智能设计

程序会输出论文题目建议、论文结构、章节写作目标、文献补充方向和后续写作建议，并默认将结果保存到：

generated_outline.md

### 运行方式二：命令行参数输入

python src/outline_generator.py "LLM 辅助 CAD 智能设计"

这种方式不需要在程序运行后再手动输入主题。

### 运行方式三：指定输出文件名

python src/outline_generator.py "LLM 辅助 CAD 智能设计" --output cad_outline.md

这种方式可以将生成结果保存到自定义 Markdown 文件中，避免每次运行都覆盖 generated_outline.md。

## 测试说明

当前项目提供了一个简单测试脚本，用于验证不同研究主题是否能够被识别为不同研究方向。

测试文件路径：

tests/test_outline_generator.py

运行方式：

python tests/test_outline_generator.py

如果测试通过，终端会输出：

All tests passed.
